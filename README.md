# Summarize It

Минимальное Chrome-расширение, которое получает полную расшифровку обычного YouTube-видео, сохраняет таймкоды читаемых блоков и отправляет запрос на суммаризацию в новую беседу ChatGPT или Perplexity.

## Разработка

Требуется Node.js 20 и Yarn 1.

```sh
yarn install
yarn test
yarn typecheck
yarn build
```

После сборки загрузите папку `dist_chrome` через `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение».

## Границы MVP

- Только обычные публичные страницы `youtube.com/watch` с доступными субтитрами.
- ChatGPT и Perplexity через их веб-интерфейсы; API-ключи и backend не используются.
- Расшифровка не сокращается и не разбивается на несколько сообщений ИИ.
- Полный продуктовый скоуп описан в `docs/prds/youtube-transcript-ai-handoff.md`.
