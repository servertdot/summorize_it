# Summarize It

Summarize It helps users start a summary of a YouTube video in an external AI service without generating the summary inside the extension itself.

## Language

**Caption track**:
One caption option available for a video, with a specific language, origin, and segment timing.
_Avoid_: Translation, transcript

**Transcript**:
The selected caption track after technical noise is removed, preserving meaningful text and useful timing.
_Avoid_: Summary, captions

**Transcript block**:
A readable group of consecutive transcript segments with one starting timestamp, similar to a paragraph in Obsidian Web Clipper.
_Avoid_: Individual utterance, fixed 30-second interval

**Start summarization**:
Transfer the complete prepared prompt to a new conversation in the selected AI service and submit it automatically so the external service starts generating a result.
_Avoid_: Receive summary, open AI service

**Manual completion**:
A fallback flow in which automatic submission is blocked and the complete prepared prompt remains available for the user to submit manually.
_Avoid_: Successful submission

**Complete transcript**:
All meaningful text available from the selected caption track, without hidden shortening or truncation, even when an external AI service cannot accept it in a single prompt.
_Avoid_: Shortened captions, partial transcript

**Summary language**:
The language selected by the user for the result generated by the external AI service. It does not need to match the transcript language.
_Avoid_: Caption language, video language
