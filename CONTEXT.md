# Summarize It

Summarize It помогает пользователю запускать суммаризацию YouTube-видео во внешнем ИИ-сервисе, не создавая собственную суммаризацию внутри расширения.

## Language

**Дорожка субтитров**:
Один доступный для видео вариант субтитров с определенными языком, происхождением и временной привязкой сегментов.
_Avoid_: Перевод, расшифровка

**Расшифровка**:
Выбранная дорожка субтитров после удаления технического шума, с сохранением содержательного текста и полезной временной привязки.
_Avoid_: Суммаризация, субтитры

**Блок расшифровки**:
Читаемая группа последовательных сегментов расшифровки с одним таймкодом начала, подобная абзацу в представлении Obsidian Web Clipper.
_Avoid_: Отдельная реплика, фиксированный 30-секундный интервал

**Запуск суммаризации**:
Полная передача подготовленного запроса в новую беседу выбранного ИИ-сервиса и его автоматическая отправка, после которой внешний сервис начинает генерировать результат.
_Avoid_: Получение суммаризации, открытие ИИ-сервиса

**Ручное завершение**:
Запасной сценарий, в котором автоматическая отправка заблокирована, а полностью подготовленный запрос остается доступен пользователю для самостоятельной отправки.
_Avoid_: Успешная отправка

**Полная расшифровка**:
Весь доступный содержательный текст выбранной дорожки субтитров без скрытого сокращения или обрезки, даже если внешний ИИ-сервис не способен принять его одним запросом.
_Avoid_: Сокращенные субтитры, частичная расшифровка

**Язык суммаризации**:
Выбранный пользователем язык, на котором внешний ИИ-сервис должен сформировать результат; он не обязан совпадать с языком расшифровки.
_Avoid_: Язык субтитров, язык видео
